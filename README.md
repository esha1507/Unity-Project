The title of my game is **DELIVERY DASH.**

Delivery Dash is a **2D**, top-down arcade game developed in Unity using C# that challenges players to step into the shoes of a urban delivery agent. The game focuses on fast-paced movement, path navigation, and state-driven game mechanics.

**Control Mapping**

**W** (Accelerate / Forward): Applies forward force to move the vehicle straight ahead relative to its current direction.

**S** (Reverse / Brake): Applies backward force to slow down, brake, or reverse the delivery vehicle when stationary.

**A** (Steer Left): Applies torque to rotate the vehicle counter-clockwise, turning it to the left.

**D** (Steer Right): Applies torque to rotate the vehicle clockwise, turning it to the right.
